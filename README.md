# CashFlow101Form

Мобильное приложение — электронная замена бумажного бланка игры CashFlow 101 (Роберт Кийосаки). Стек: Expo + React Native + TypeScript.

## Возможности (план)

- До 4 локальных игровых профилей с автосохранением
- Автоподсчёт всех показателей бланка (общий доход/расход, пассивный доход, денежный поток)
- Каталоги акций / малых сделок / крупных сделок / бизнесов большого круга
- Учёт детей, банковского кредита, благотворительности
- Переход на Скоростную дорожку с условием победы

## Структура

```
cashflow-app/
├── config/        ← все игровые данные (JSON, легко править)
├── lib/           ← TS-типы, Zod-схемы, чистые функции
├── app/           ← экраны (Expo Router) — будут добавлены на шаге 2
└── components/    ← UI-компоненты — шаг 2
```

См. `config/README.md` про формат игровых данных.

## Запуск (после шага 2)

```bash
npm install
npx expo start
```

Сборка APK через EAS:
```bash
npx eas build --platform android --profile preview
```
