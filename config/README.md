# /config

Игровые данные. Все JSON-файлы валидируются Zod-схемами в `lib/schema.ts` при старте приложения.

| Файл | Что содержит | Источник |
|---|---|---|
| `professions.json` | 12 стартовых карточек: зарплата, статьи расходов, начальные активы и долги | xlsx «Профессии» |
| `stocks.json` | Тикеры акций. `hasDeposit: true` — даёт фиксированный дивиденд `dividendPerShare`/мес на акцию. Остальные торгуются по цене | xlsx «Наименование объектов» |
| `small-deals.json` | Каталог малых сделок (только названия для автокомплита; цена/cashflow вводятся вручную с физической карточки) | xlsx «Наименование объектов» |
| `big-deals.json` | Каталог крупных сделок | xlsx «Наименование объектов» |
| `fast-track.json` | Бизнесы скоростной дорожки: `kind: "monthly"` — регулярный cashflow; `kind: "oneTime"` — разовая выплата (IPO). `diceRequired` — нужное значение на кубике | xlsx «Большой круг» |
| `rules.json` | Игровые коэффициенты: лимит детей, банковский кредит ($100/мес на $1000), множитель пассивного дохода при выходе на ВТ (×100), условие победы (+$50k), благотворительность 10% и т.д. | официальные правила |

## Правила редактирования

- **Не трогайте `id`** — на него ссылаются сохранения игроков. Если нужно переименовать сделку — меняйте только `name`.
- **Цифры** в JSON без кавычек, без `_` и пробелов. `1000`, не `1_000` и не `"1 000"`.
- **Дробные значения** — `0.1`, не `,1` и не `.1`.
- После любых правок перезапустите приложение. Если схема нарушена — на старте увидите красный экран с указанием поля, не молчаливый сбой.
